# Unity — User Types & Workflows

## User Types

| Type | Description |
|---|---|
| **Renter** | Browses and rents items from merchants |
| **Merchant** | Lists items for rent, manages bookings and payouts |
| **Both** | Can do both (most common — platform encourages dual participation) |
| **Ambassador** | Creator/influencer who promotes Unity for commission |
| **Admin** | Unity internal team — manages disputes, verifications, fraud |

---

## Renter Journey

### Pre-Booking
1. Discover Unity (social, ambassador, Google, word of mouth)
2. Browse listings (no account required)
3. Create account → role: Renter
4. Complete KYC (ID, proof of residence, liveness check) — or skip for now
5. Complete onboarding quiz
6. Browse & search listings
7. Filter by category, location, price, dates
8. View item detail page
9. Check eligibility (Unity Score vs merchant requirements)
10. Select dates (must meet min rental days)
11. Submit booking request

### Booking & Payment
12. Merchant approves request
13. Renter receives approval notification
14. Checkout: pay rental fee + deposit (held in escrow) + shipping
15. Booking confirmed (PayFast onsite payment)

### During Rental
16. Merchant ships / hands over item
17. Renter receives item, records timestamped condition video/photos
18. Uses item for rental period
19. Receives return reminders (push + SMS)

### Return & Review
20. Returns item via agreed method
21. Merchant inspects and confirms return condition
22. If good: deposit auto-released to renter
23. If issue: dispute raised, funds held
24. Both parties leave reviews
25. Unity Score updated

## Merchant Journey

### Pre-Listing
1. Create account → role: Merchant (or Both)
2. Complete KYC — or skip for now (required before first listing goes live)
3. Link bank account for payouts

### Creating a Listing
4. Click "List an Item"
5. Fill in: category, title, description, condition
6. Upload photos/videos (min 3)
7. Upload proof of ownership (receipt, serial number, warranty)
8. Set pricing (daily/weekly rates)
9. Set availability calendar
10. Configure per-listing settings (deposit, min days, shipping, eligibility, affiliate toggle)
11. Submit for verification
12. Listing goes live

### Managing Bookings
13. Receive booking request notification
14. Review renter profile (Unity Score, KYC status, history)
15. Approve or decline (optional: chat with renter first)
16. On approval: payment collected from renter, held in escrow

### Return & Payout
17. Item returned by renter
18. Inspect item, upload post-rental photos/video
19. Confirm: Good / Damaged / Missing
20. If good: escrow released → payout to merchant (rental fee minus Unity commission)
21. If issue: raise dispute
22. Rate renter
23. Re-list item

## Ambassador Journey

### Application
1. Apply via `/ambassadors` page
2. Eligibility: active Unity account, 3+ active social platforms, 10k+ followers
3. Approved → receive unique referral link + code

### Earning
4. Create content promoting Unity (must disclose #UnityPartner)
5. Referred user signs up + completes first rental
6. Ambassador earns 7.5% of first rental fee
7. All subsequent rentals by that user = 1–2% for 12 months
8. R50 per new merchant listing by referred user

### Tiers
- **Explorer:** 1–19 conversions/month → 1% LTV share
- **Pioneer:** 20+ conversions/month → 2% LTV share

### Payment
- Monthly payout (first 10 business days of following month)
- Minimum R500 threshold
- Paid to linked bank account

## Admin Workflow

### Dispute Resolution Process
1. Dispute raised (merchant or renter)
2. Both parties upload evidence (photos, videos, chat logs)
3. Admin reviews within 48–72 hours
4. Decision: release deposit / partial refund / full hold
5. If fraud confirmed: Unity Score penalty + account action

### Strike System (Both Renters & Merchants)
- **Offence 1:** Warning
- **Offence 2:** Account suspension
- **Offence 3:** Financial penalty
- **Offence 4:** Permanent ban (record visible to all users)
