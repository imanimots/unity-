# Wave 0 Merchant Outreach Kit

Scripts, cadence, and positioning for first-contact outreach to Wave 0 founding-merchant prospects. See `docs/WAVE0_SUPPLY_ACQUISITION.md` for the recruitment plan this supports and `docs/WAVE0_FIRST_CONTACT_SHORTLIST.md` for who to contact. **Nothing in this document has been sent to anyone** — every message below is a draft awaiting approval before any live outreach begins.

## Founding Merchant Positioning

Wave 0 is a controlled, no-real-money pilot. The pitch must never promise current rental income, bookings, customers, insurance, financial returns, or guaranteed preferential treatment after launch.

Position prospects as **Founding Wave 0 Merchants**, with these honest reasons to participate:
- Early access to Unity before public rollout
- Opportunity to test the marketplace experience before real transactions begin
- Early merchant profile/listing setup — ready to go the moment commercial activity starts
- A direct feedback channel to the Unity team
- Influence over how the merchant workflow works before wider launch
- First-mover positioning when commercial transactions later activate

**Never promise**: income, bookings, customers, insurance, financial returns, or guaranteed preferential treatment.

## Merchant Value Proposition (future vs. current, clearly separated)

Unity ultimately aims to help merchants:
- Expose under-utilized inventory to additional users
- Create another digital discovery channel for their items
- Manage listings through a dedicated marketplace
- Reach users interested in temporary access rather than ownership
- Participate in a growing rental/reuse economy

**Current Wave 0 reality, stated plainly alongside the above**: this is pilot testing with no real money involved yet. The value right now is early setup and feedback — not revenue.

## First-Contact Scripts

### A. Email

**Subject**: Early access — Unity founding merchant pilot

Hi [Contact Name / "there" if no name available],

I'm reaching out from Unity, a new South African marketplace for renting and accessing useful items instead of buying them.

We're preparing a small, controlled, nationwide founding-merchant pilot and are inviting a limited number of rental businesses and equipment owners — like [Business Name] — to test the merchant experience and list suitable inventory before our wider public launch.

This pilot phase doesn't involve real transactions yet — it's about setting up your profile, listing a few items, and giving us feedback on the experience. There's no obligation to participate.

If you're open to a short conversation, happy to share more details.

Best,
[Name] — Unity

### B. WhatsApp

Hi! I'm with Unity, a new SA marketplace for renting/accessing useful items. We're inviting a small number of rental businesses like [Business Name] to join an early founding-merchant pilot — testing the platform before public launch, no obligation. Open to a quick chat?

### C. Telephone Opening Script

"Hi, my name is [Name], I'm calling from Unity — we're building a new South African marketplace for renting items. We're putting together a small group of founding merchants to test the platform before we launch publicly, and [Business Name] looked like a great fit given [specific reason]. Do you have a couple of minutes, or would it be better to send you something in writing first?"

### D. LinkedIn / Social DM

Hi [Name], I'm with Unity — we're building a new South African peer-to-peer rental marketplace and are inviting a small number of founding merchants to test it before public launch. [Business Name] looked like a strong fit. Open to a short chat? No pressure either way.

## Outreach Cadence

| Day | Action |
|---|---|
| Day 0 | First contact |
| Day 3 | Short follow-up |
| Day 7 | Second/final follow-up |
| Day 14 | Close out — mark NO RESPONSE if nothing heard |

Maximum 3 outreach attempts per prospect during the initial cycle. Do not spam.

## Follow-Up & Response Messages

**Follow-Up 1** (Day 3): "Hi [Name], just following up on my note about Unity's founding-merchant pilot — totally fine if now isn't the right time. Happy to answer any questions."

**Follow-Up 2 / Final** (Day 7): "Hi [Name], last check-in on this — if you're interested in Unity's founding-merchant pilot, I'd love to chat, otherwise no worries at all and thanks for your time."

**Interested Response**: "That's great to hear! Here's what happens next: a quick account setup, a short ID check, and then we'll help you list your first item or two. Would a 10-15 minute call work to walk through it?"

**Request for More Information Response**: "Happy to explain more — Unity is a peer-to-peer rental marketplace launching a controlled pilot in South Africa. Right now it's invite-only and no real transactions happen yet; it's about setting up and testing. [Attach/restate value proposition.] Let me know what else would help."

**Not Now Response**: "No problem at all — thanks for letting me know. Would it be okay if we checked back in a few months once we're further along?"

**Decline Acknowledgement**: "Totally understood, thank you for considering it. Wishing you all the best with [Business Name]."

## Merchant Discovery Call Checklist (10-15 minutes)

1. Business/activity type — what do they do day to day?
2. Inventory categories — which Wave 0 category fits (outdoor/events/sports/baby/tools)?
3. Approximate number of suitable items they could list
4. Current rental model (if they already rent things out) — how does it work today?
5. Service area — where do they operate?
6. Collection availability — can renters self-collect?
7. Delivery model, if any (not required for Wave 0 — self-collection only, see `docs/WAVE0_OPERATIONS.md`)
8. Existing online booking/listing channels (website, social, other marketplaces)
9. Interest in joining the pilot — gauge genuine interest, not just politeness
10. Willingness to complete merchant KYC
11. Willingness to provide item photos (minimum 3 per listing)
12. Willingness to provide ownership evidence where required (medium/high risk tier items)
13. Likely timeframe to onboard

Do not ask for unnecessary confidential commercial information (e.g. revenue, supplier pricing, customer lists).

## Recruitment Funnel Stages

```
PROSPECT IDENTIFIED → CONTACTED → REPLIED → QUALIFIED → INTERESTED → ONBOARDING
→ KYC COMPLETE → LISTINGS STARTED → LISTINGS QUALITY-APPROVED → OWNERSHIP VERIFIED → READY
                                                                            ↘ DECLINED
                                                                            ↘ NO RESPONSE
```

Track actual conversions as they genuinely happen — never mark a stage reached before it has.

## First Recruitment Cycle Plan

- **Day 1**: research complete, shortlist finalized (this phase's output)
- **Days 2-4**: contact the first 25 shortlisted prospects, at roughly 8-10 first contacts per day
- Do not contact all 75 researched prospects immediately — use the first 25 to learn which merchant profile responds best before expanding

## Learning Loop (after the first 25 are contacted)

Report: contacted / replies / interested / qualified / onboarding / declined / no response counts, then identify:
- Best-performing category
- Best-performing merchant type (Tier A vs B vs C)
- Best-performing contact channel (email vs WhatsApp vs phone vs DM)
- Most common objection
- Most common onboarding concern

Use this evidence to choose the next 25 prospects from the remaining researched pool — do not change the nationwide strategy based on a small sample without real evidence.
