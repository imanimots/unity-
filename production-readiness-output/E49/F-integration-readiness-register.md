## The one new finding this section surfaces

**The PayFast/Peach naming discrepancy is a real, previously-unflagged inconsistency between this project's own master brief (`CLAUDE.md`) and its actual codebase.** `CLAUDE.md` states "PayFast — integrated and live (onsite integration)" as a confirmed, non-negotiable build spec, but every payment-provider code path in `src/lib/payments/` implements Peach Payments, not PayFast. This should be resolved with a decision (update the documentation to reflect Peach, or treat PayFast as still-outstanding work) rather than left as a silent mismatch between stated intent and built reality.
